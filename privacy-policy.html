Privacy Policy

Ink Battle

Last updated: September 23, 2026

Ink Battle is designed as a local-first game. It does not use developer-run accounts, ads, analytics SDKs, or a hosted gameplay backend.

Developer

This app is developed by Roni Tervo. The public project page is github.com/RONITERVO/Ink-Battle.

Information Stored On Your Device

The game may store the following information locally on your device or in your browser site data:

  • Game progress, such as completed difficulties.
  • Gameplay preferences, such as music mute state.
  • Director chat pacts, short local notes, recent in-game director memory, and model status used to keep the opponent behavior consistent.
  • Cached web app files used by the Progressive Web App and Android WebView shell.
  • An optional Gemma model file if you choose to download it for local on-device opponent replies. The web version saves this separately in browser storage, along with its inference runtime.

This locally stored information is used to run the game, remember settings, and support offline play. The developer does not receive this information from the app.

Network Use

The web version can request game files, fonts, and audio files from GitHub Pages or the configured hosting location. Both the web and Android versions can download an optional Gemma model after you choose to download it. The web model comes from Hugging Face and its download CDN; the runtime comes from this game's host. No model download begins automatically.

If you choose the optional Gemma download, the model file is requested from the configured model host. That host may receive normal network request information such as IP address, request time, and user agent under its own privacy practices.

AI And Gameplay Text

The deterministic opponent runs locally. When the optional Android Gemma feature is installed and loaded, the app sends in-game tactical context, recent player/director text, and a generated tactical image to the on-device model for local processing. This context is not sent to a developer server.

The optional web Gemma feature processes a text summary of the battle and recent chat locally on your GPU. It does not upload these prompts or replies. No inference API key or remote AI service is used.

Data Sharing

The app does not sell personal information. The app does not include advertising SDKs or developer-run analytics SDKs. The developer does not share gameplay progress, local chat text, or local model context with third parties.

Deletion

You can delete locally stored app data by clearing the browser site data for the GitHub Pages site, clearing Android app storage, or uninstalling the Android app. Clearing Android app storage or uninstalling the app also removes the optional downloaded model file.

On the web, Gemma settings also offer Turn off (releases the model from memory) and Remove download (deletes the model and runtime cache while keeping progress). The browser may evict saved files when storage is low.

Children

The app is a strategy game and does not knowingly collect personal information from children. If you believe personal information was provided through a support channel, contact the developer so it can be removed.

Changes

This policy may be updated when the app changes. The latest version will be hosted at this page.

Contact

For privacy questions, open an issue at github.com/RONITERVO/Ink-Battle/issues or contact the developer through github.com/RONITERVO.
